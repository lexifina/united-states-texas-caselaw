# Ex parte Hinkle

## Majority (MORRISON, Judge.)

OPINION
MORRISON, Judge.
This, is an extradition proceeding.
Since this case was received by this Court, we have officially been notified that the Governor of this State has recalled his Executive Warrant (Ex parte Oxford, 158 Tex.Cr.R. 435, 256 S.W.2d 105) thus rendering the question before us in the writ moot.
This being so the appeal is dismissed.
It is so ordered.
DOUGLAS, J., not participating.
